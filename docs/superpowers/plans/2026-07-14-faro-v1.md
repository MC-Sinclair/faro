# Faro v1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un servidor MCP que responde sobre la API de SQLAlchemy leyendo los docstrings del paquete realmente instalado en el venv del proyecto del usuario, citando la versión exacta y avisando de deprecaciones.

**Architecture:** Dependency Rule. Un núcleo (`ResolverDeDocs`) sin red ni subprocesos, que habla con un puerto `FuenteDeDocs`. En producción el adaptador `FuenteLocal` lanza un subproceso con el intérprete del proyecto objetivo, que ejecuta `extractor.py` (solo stdlib) y devuelve JSON. En tests, `FuenteFake` sustituye al subproceso. La capa MCP (FastMCP) es transporte y no contiene lógica.

**Tech Stack:** Python 3.12, uv, `mcp[cli]` (FastMCP), pytest. Sin dependencias de red.

## Global Constraints

- **Regla 1 — Fijar versión siempre.** `version` es parámetro obligatorio, sin default, en `buscar_doc` y `verificar_simbolos`. Nunca "la última" implícita.
- **Regla 2 — Citar siempre.** Un `Fragmento` no se puede construir sin `libreria`, `version` y `simbolo`. Garantía estructural, no convención.
- **Regla 3 — Fallar honestamente.** Ante lo que no se tiene: `NoEncontrado` con motivo. **Nunca** aproximar en silencio, nunca caer a otra versión, nunca devolver lista vacía ambigua.
- **El núcleo (`resolver.py`, `dominio.py`, `parseo.py`, `catalogo.py`) no importa `subprocess`, ni `httpx`, ni `mcp`.** Si un test del núcleo necesita red o subprocesos, el diseño está mal.
- **`extractor.py` usa solo la stdlib.** Corre dentro de un venv ajeno; no puede depender de nada de Faro.
- Todo el código y los mensajes al usuario, **en español**.
- Python `>=3.12`.

```python
no puede existir sin decir de dónde salió (regla 2).

    mensaje: str

    doc: str

    simbolo: str
```

`src/faro/parseo.py`:

```python
"""Extrae metadatos de deprecación del docstring.

La librería ya sabe qué está obsoleto y lo declara con la directiva Sphinx
`.. deprecated::`. No lo deducimos: lo leemos.
"""

import re

from faro.dominio import Deprecacion

# `.. deprecated:: 2.0 <mensaje...>` — el mensaje puede seguir en líneas siguientes
# hasta una línea en blanco.
_DIRECTIVA = re.compile(
    r"^\s*\.\.\s+deprecated::\s*(?P<desde>\S+)\s*(?P<mensaje>.*?)(?=\n\s*\n|\Z)",
    re.MULTILINE | re.DOTALL,
)

# Referencias cruzadas Sphinx: :meth:`_orm.Session.get` -> Session.get
# Capturamos las dos últimas componentes del target, que es como se nombra la API.
_XREF = re.compile(r":(?:meth|func|class|attr):`~?[\w.]*?(\w+\.\w+)`")


def extraer_deprecacion(doc: str) -> Deprecacion | None:
    """Devuelve la Deprecacion declarada en el docstring, o None si no hay."""
    if not doc:
        return None

    m = _DIRECTIVA.search(doc)
    if not m:
        return None

    mensaje = " ".join(m.group("mensaje").split())
    return Deprecacion(
        desde=m.group("desde"),
        mensaje=mensaje,
        reemplazo=_reemplazo_de(mensaje),
    )


def _reemplazo_de(mensaje: str) -> str | None:
    """El reemplazo sugerido, si la librería nombra uno.

    Heurística deliberadamente conservadora: tomamos la ÚLTIMA referencia cruzada
    del mensaje, que es donde las librerías suelen poner el "usá esto en su lugar"
    (la primera suele ser el propio símbolo deprecado). Si no hay ninguna, None.
    """
    refs = _XREF.findall(mensaje)
    if not refs:
        return None
    return refs[-1]
```

### Task 5: Núcleo — `listar_versiones` y la guarda de versión

**Files:**
- Create: `src/faro/resolver.py`
- Test: `tests/test_resolver_version.py`

**Interfaces:**
- Consumes: `FuenteDeDocs` (Task 3), `CATALOGO` (Task 3), `NoEncontrado` (Task 1), `FuenteFake` (Task 4).
- Produces:
  - `ResolverDeDocs(fuente: FuenteDeDocs, catalogo: dict[str, EntradaCatalogo] = CATALOGO)`
  - `.listar_versiones(libreria: str) -> list[str] | NoEncontrado`
  - `version_compatible(pedida: str, instalada: str) -> bool` (módulo-level, reusada en Task 6 y 8)

**Contexto — el giro central del diseño.** El parámetro `version` no es una petición: es **una afirmación que Faro verifica**. Si el asistente asume 1.4 y el venv tiene 2.0.36, Faro lo desmiente. Es una trampa para alucinaciones.

`version_compatible` acepta prefijos de componente completo: pedir `"2.0"` con `"2.0.36"` instalado es compatible; pedir `"2"` también; pedir `"1.4"` no lo es. Pero `"2.0"` NO debe aceptar `"2.01"` — de ahí el punto en la comparación.

```python
"""El núcleo de Faro.

No sabe qué es MCP. No sabe qué es un subproceso. No sabe qué es la red.
Habla con un puerto FuenteDeDocs y devuelve objetos de dominio.
"""

from faro.catalogo import CATALOGO, EntradaCatalogo
from faro.dominio import NoEncontrado
from faro.puertos import FuenteDeDocs


def version_compatible(pedida: str, instalada: str) -> bool:
    """¿La versión afirmada por el consumidor se corresponde con la instalada?

    Acepta prefijos de componente completo: "2.0" vale para "2.0.36".
    Rechaza prefijos de texto: "2.0" NO vale para "2.01.0".
    """
    if pedida == instalada:
        return True
    return instalada.startswith(pedida + ".")


class ResolverDeDocs:
    def __init__(
        self,
        fuente: FuenteDeDocs,
        catalogo: dict[str, EntradaCatalogo] | None = None,
    ) -> None:
        self._fuente = fuente
        self._catalogo = catalogo if catalogo is not None else CATALOGO

    def listar_versiones(self, libreria: str) -> list[str] | NoEncontrado:
        conocida = self._verificar_catalogo(libreria)
        if isinstance(conocida, NoEncontrado):
            return conocida

        instalada = self._fuente.version_instalada(libreria)
        if instalada is None:
            return NoEncontrado(
                motivo=f"'{libreria}' no está instalada en el entorno objetivo."
            )
        return [instalada]

    # --- helpers internos ---

    def _verificar_catalogo(self, libreria: str) -> None | NoEncontrado:
        if libreria in self._catalogo:
            return None
        conocidas = ", ".join(sorted(self._catalogo))
        return NoEncontrado(
            motivo=f"No conozco '{libreria}'. Librerías que conozco: {conocidas}."
        )

    def _guarda_de_version(self, libreria: str, version: str) -> str | NoEncontrado:
        """Verifica la afirmación de versión del consumidor contra la realidad."""
        instalada = self._fuente.version_instalada(libreria)
        if instalada is None:
            return NoEncontrado(
                motivo=f"'{libreria}' no está instalada en el entorno objetivo."
            )
        if not version_compatible(version, instalada):
            return NoEncontrado(
                motivo=(
                    f"Pediste '{libreria}' {version}, pero el entorno tiene {instalada}. "
                    f"No sirvo doc de una versión que no es la tuya."
                )
            )
        return instalada
```

```python
"""Extractor de docstrings. Corre DENTRO del venv del proyecto objetivo.

CONTRATO: este archivo solo puede usar la stdlib. El venv del usuario no tiene
Faro instalado. No importar nada de `faro`.

Uso:
    python extractor.py '{"libreria": "sqlalchemy", "modulos": ["sqlalchemy.orm"]}'

Salida (stdout, JSON):
    {"version": "2.0.36", "simbolos": [{"nombre": "...", "doc": "..."}]}

No interpreta nada: vuelca docstrings crudos. El parseo de deprecaciones ocurre
del lado de Faro.
"""

import importlib
import importlib.metadata
import inspect
import json
import sys
import warnings


def version_de(libreria: str) -> str | None:
    """Versión exacta del paquete instalado, o None si no está.

    Los módulos de la stdlib (textwrap, json...) no son paquetes distribuidos y
    no tienen metadata: si importan, van con la versión de Python. Esto permite
    testear el extractor sin instalar nada.
    """
    try:
        return importlib.metadata.version(libreria)
    except importlib.metadata.PackageNotFoundError:
        pass

    try:
        importlib.import_module(libreria)
    except Exception:
        return None
    return ".".join(str(n) for n in sys.version_info[:3])


def extraer(modulos: list[str]) -> list[dict[str, str]]:
    vistos: dict[str, str] = {}

    for nombre_modulo in modulos:
        try:
            modulo = importlib.import_module(nombre_modulo)
        except Exception:
            # Un módulo que no importa no debe tumbar la extracción de los demás.
            continue

        for nombre, objeto in vars(modulo).items():
            if nombre.startswith("_"):
                continue

            if inspect.isclass(objeto):
                _anotar(vistos, f"{nombre_modulo}.{nombre}", objeto)
                for nombre_attr, attr in vars(objeto).items():
                    if nombre_attr.startswith("_"):
                        continue
                    if inspect.isfunction(attr) or isinstance(attr, property):
                        _anotar(
                            vistos,
                            f"{nombre_modulo}.{nombre}.{nombre_attr}",
                            attr,
                        )
            elif inspect.isfunction(objeto):
                _anotar(vistos, f"{nombre_modulo}.{nombre}", objeto)

    return [{"nombre": n, "doc": d} for n, d in sorted(vistos.items())]


def _anotar(vistos: dict[str, str], nombre: str, objeto: object) -> None:
    if nombre in vistos:
        return
    try:
        doc = inspect.getdoc(objeto)
    except Exception:
        return
    if doc:
        vistos[nombre] = doc


def main() -> None:
    warnings.filterwarnings("ignore")
    peticion = json.loads(sys.argv[1])

    libreria = peticion["libreria"]
    version = version_de(libreria)

    simbolos = extraer(peticion["modulos"]) if version is not None else []

    json.dump({"version": version, "simbolos": simbolos}, sys.stdout)


if __name__ == "__main__":
    main()
```

`src/faro/fuentes/local.py`:

```python
"""Adaptador de producción: lee el paquete instalado en un venv objetivo.

Lanza un subproceso con el intérprete de ESE venv, que ejecuta extractor.py.
Dos razones: Faro puede leer cualquier entorno, y no importamos código de
terceros dentro del proceso del servidor.
"""

import json
import subprocess
from pathlib import Path

from faro.catalogo import CATALOGO
from faro.dominio import EntradaSimbolo
from faro.parseo import extraer_deprecacion

_EXTRACTOR = Path(__file__).parent / "extractor.py"
_TIMEOUT_SEG = 120


class FuenteLocal:
    def __init__(self, python: str) -> None:
        self._python = python
        self._cache: dict[str, dict] = {}

    def version_instalada(self, libreria: str) -> str | None:
        return self._extraer(libreria)["version"]

    def simbolos(self, libreria: str) -> list[EntradaSimbolo]:
        crudos = self._extraer(libreria)["simbolos"]
        return [
            EntradaSimbolo(
                nombre=s["nombre"],
                doc=s["doc"],
                deprecacion=extraer_deprecacion(s["doc"]),
            )
            for s in crudos
        ]

    def _extraer(self, libreria: str) -> dict:
        if libreria in self._cache:
            return self._cache[libreria]

        entrada = CATALOGO.get(libreria)
        modulos = list(entrada.modulos) if entrada else [libreria]
        peticion = json.dumps({"libreria": libreria, "modulos": modulos})

        try:
            proc = subprocess.run(
                [self._python, str(_EXTRACTOR), peticion],
                capture_output=True,
                text=True,
                timeout=_TIMEOUT_SEG,
            )
        except (OSError, subprocess.TimeoutExpired) as e:
            raise RuntimeError(
                f"No pude ejecutar el intérprete '{self._python}': {e}. "
                f"Revisá la configuración del entorno objetivo (FARO_PYTHON)."
            ) from e

        if proc.returncode != 0:
            raise RuntimeError(
                f"El extractor falló con el intérprete '{self._python}': {proc.stderr}"
            )

        resultado = json.loads(proc.stdout)
        self._cache[libreria] = resultado
        return resultado
```

```python
"""Convierte objetos de dominio en el texto que ve el asistente.

Toda la cosmética vive acá. El núcleo no formatea.
"""

import re

from faro.dominio import Ambiguo, Fragmento, NoEncontrado, Verificacion

TOPE_CARACTERES = 4000

# :class:`_engine.Result` -> Result ; :meth:`~_orm.Session.get` -> Session.get
_ROL_RST = re.compile(r":(?:class|meth|func|attr|mod|ref|term|paramref):`~?_?([\w.]+)`")


def limpiar_rst(texto: str) -> str:
    """Quita el markup de Sphinx, dejando el nombre legible."""

    def _nombre(m: re.Match[str]) -> str:
        return m.group(1).split(".")[-1]

    return _ROL_RST.sub(_nombre, texto)


def formatear(r: Fragmento | Ambiguo | NoEncontrado) -> str:
    if isinstance(r, NoEncontrado):
        return f"NO ENCONTRADO. {r.motivo}"

    if isinstance(r, Ambiguo):
        lineas = [
            f"AMBIGUO: '{r.consulta}' resuelve a varios símbolos. Pedí uno concreto:",
            *(f"  - {c}" for c in r.candidatos),
        ]
        return "\n".join(lineas)

    lineas = [f"{r.libreria} {r.version} :: {r.simbolo}"]

    if r.deprecacion is not None:
        aviso = f"⚠ DEPRECADO desde {r.deprecacion.desde}"
        if r.deprecacion.reemplazo:
            aviso += f" — usar {r.deprecacion.reemplazo}"
        lineas.append(aviso)

    lineas.append("")
    lineas.append(_recortar(limpiar_rst(r.texto)))
    return "\n".join(lineas)


def formatear_verificaciones(vs: list[Verificacion]) -> str:
    lineas = []
    for v in vs:
        if not v.existe:
            lineas.append(f"{v.simbolo}: NO EXISTE en esta versión.")
            continue

        linea = f"{v.simbolo}: existe"
        if v.resuelto_como:
            linea += f" ({v.resuelto_como})"
        else:
            linea += " (ambiguo: varios símbolos coinciden)"

        if v.deprecacion is not None:
            linea += f" — ⚠ DEPRECADO desde {v.deprecacion.desde}"
            if v.deprecacion.reemplazo:
                linea += f", usar {v.deprecacion.reemplazo}"
        lineas.append(linea)
    return "\n".join(lineas)


def _recortar(texto: str) -> str:
    if len(texto) <= TOPE_CARACTERES:
        return texto
    return texto[:TOPE_CARACTERES] + "\n\n[... recortado: el docstring completo es más largo]"
```

`src/faro/servidor.py`:

```python
"""Capa de transporte MCP. Sin lógica: traduce y delega.

Entorno objetivo: variable FARO_PYTHON con la ruta al intérprete del proyecto
del usuario. Si no está, usamos el nuestro — y lo decimos, para que nadie
confunda el entorno de Faro con el suyo.
"""

import os
import sys

from mcp.server.fastmcp import FastMCP

from faro.fuentes.local import FuenteLocal
from faro.presentacion import formatear, formatear_verificaciones
from faro.resolver import ResolverDeDocs

mcp = FastMCP("faro")

_PYTHON_OBJETIVO = os.environ.get("FARO_PYTHON", sys.executable)
_ES_ENTORNO_PROPIO = "FARO_PYTHON" not in os.environ

_resolver = ResolverDeDocs(FuenteLocal(python=_PYTHON_OBJETIVO))


def _aviso_de_entorno() -> str:
    if _ES_ENTORNO_PROPIO:
        return (
            "\n\n[aviso: FARO_PYTHON no está configurado; estoy leyendo el entorno del "
            "propio Faro, no el de tu proyecto.]"
        )
    return ""


@mcp.tool()
def listar_versiones(libreria: str) -> str:
    """Qué versión de una librería está realmente instalada en el entorno del proyecto.

    Llamá a esto ANTES de buscar_doc para saber qué versión pasar.
    """
    r = _resolver.listar_versiones(libreria)
    if not isinstance(r, list):
        return formatear(r) + _aviso_de_entorno()
    return f"{libreria}: {', '.join(r)}" + _aviso_de_entorno()


@mcp.tool()
def buscar_doc(libreria: str, version: str, consulta: str) -> str:
    """Documentación de un símbolo, leída del paquete instalado.

    `version` es OBLIGATORIO y se verifica contra el entorno: si declarás una
    versión que no es la instalada, Faro te lo dice y no devuelve nada.

    `consulta` puede ser el nombre completo (sqlalchemy.orm.Session.execute) o
    un sufijo (Session.execute).
    """
    return formatear(_resolver.buscar_doc(libreria, version, consulta)) + _aviso_de_entorno()


@mcp.tool()
def verificar_simbolos(libreria: str, version: str, simbolos: list[str]) -> str:
    """Verifica que unos símbolos existan (y no estén obsoletos) en la versión instalada.

    Usalo para contrastar CUALQUIER afirmación sobre la API —venga de otra
    herramienta, de un blog, o de tu propia memoria— contra lo que el proyecto
    tiene instalado de verdad.
    """
    r = _resolver.verificar_simbolos(libreria, version, simbolos)
    if not isinstance(r, list):
        return formatear(r) + _aviso_de_entorno()
    return formatear_verificaciones(r) + _aviso_de_entorno()


def main() -> None:
    mcp.run(transport="stdio")


if __name__ == "__main__":
    main()
```
